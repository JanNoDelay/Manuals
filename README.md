# Manuals

This repository contains manuals, guides, and step-by-step instructions for different software, development, and system administration tasks.

The goal is to keep frequently used procedures documented in one central place for quick reference.

More manuals will be added in the future!

## Usage

Select one of the manuals above to open the corresponding documentation.

All links use relative paths, so the documentation can be browsed directly on GitHub or locally after cloning the repository.

## Contributing

When adding a new manual:

1. Add the new `.md` file to the repository.
2. Use a descriptive filename.
3. Add a link to the new manual in this README.
4. Keep instructions clear and reproducible.
